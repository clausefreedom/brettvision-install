# BrettVision install
Paste in Terminal on the Mac:

    curl -fsSL https://raw.githubusercontent.com/clausefreedom/brettvision-install/main/install.sh | bash

Read `install.sh` first if you like; it is short. Installs Homebrew, uv, git, Tailscale, Claude Code and the BrettVision field code. Safe to re-run.
